# AI Job Search Automation using n8n + Ollama

An intelligent AI-powered job application automation workflow built with n8n.

## Features

- Automated job scraping from RSS feeds
- AI-generated personalized cover letters
- PDF generation
- Automatic recruiter email extraction
- Gmail application delivery
- Telegram notifications
- Google Sheets tracking
- Local AI using Ollama

## Technologies
- n8n
- Ollama
- Gmail API
- Telegram Bot API
- Google Sheets
- RSS Feed
- JavaScript
- Docker

## Workflow Overview
- Schedule Trigger
- RSS Feed Read
- AI Processing
- Cover Letter Generation
- PDF Generation
- Recruiter Email Extraction
- Gmail Delivery
- Telegram Notification
- Google Sheet Update

Architecture

Jenkins → n8n Webhook → Logic → Telegram Alerts
